# Abhyas — Project Rules for Agents

Hermes (and any coding agent): when working in this repo, follow these rules.

## What this is
Study companion for Indian students (Class 9–12 first): derived daily plans,
spaced-revision engine, marks-driven mastery. Expo 57 + React Native 0.86,
pnpm + Turborepo monorepo. Local-first; Supabase sync arrives in P2.
Read `docs/CODEGRAPH.md` before structural work; `docs/MASTER-PLAN.md` is the
single source of truth for what remains.

## Commands
- Full gate (MUST be green before declaring anything done):
  `pnpm exec turbo run typecheck test`   (10 tasks)
- Web export for headless walks: `pnpm exec expo export --platform web --output-dir ./dist`
  then `npx serve -sl 8085 ./dist` (`-s` SPA flag is mandatory).
- Store logic tests run under vitest against Zustand directly (no DOM).

## Conventions
- Engine stays pure TS, zero RN imports, golden-tested. UI never reimplements
  domain logic — it calls engine functions.
- Styling: NativeWind v5 (Tailwind v4 CSS-first). Design tokens live ONLY in
  `apps/mobile/global.css` @theme block; `_layout.tsx` navTheme must mirror them.
- Metro gotcha: import `withNativewind` from `'nativewind/metro'`, never the
  package root (root entry requires react-native → crashes bare Node).
- Day boundary = device timezone. Carry ≤2 forward-work items, revisions never
  carried. SRS base [1,3,7,16,35] × style dial (×0.7/×1.0/×1.4).
- No silent failure states (F21/F24): every error path shows visible feedback.
- Emoji doubles as subject id in v1; plan_items.uid = `t_<topicId>` stable across re-solves.

## Definition of Done (every task)
1. Turbo typecheck+test green.
2. Behavior verified by execution (unit test or headless walk), not screenshots alone.
3. Issue closed with comment linking proof; MASTER-PLAN.md table updated in same PR.

## Agent roles
Multi-role engineering runs use the briefs in `docs/agents/AGENTS-BOARD.md`.
Dispatch = delegate_task with the role brief inline; verify results yourself
before claiming them; never merge without the full gate green.
